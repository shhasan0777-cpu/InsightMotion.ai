# InsightMotion AI

**InsightMotion AI** — это интеллектуальная веб-платформа для управления маркетплейс-бизнесом, задачами, аналитикой, контентом и AI-автоматизацией.

Проект создаётся как рабочая система для продавцов, команд и специалистов, которые работают с товарами, продвижением, SEO, рекламой, аналитикой, отзывами, вопросами, карточками товаров и ежедневными операционными задачами.

Главная идея проекта — собрать в одном интерфейсе всё, что нужно для управления продажами и продвижением на маркетплейсах, а затем усилить это искусственным интеллектом.

---

## Коротко о проекте

InsightMotion AI — это не просто сайт и не обычная админ-панель.

Это основа будущей AI-платформы, которая должна помогать бизнесу:

- планировать задачи;
- управлять рабочими процессами;
- контролировать календарь действий;
- автоматизировать рутинные операции;
- работать с AI-моделями;
- анализировать данные;
- готовить контент для карточек товаров;
- улучшать SEO;
- отслеживать маркетинговые активности;
- помогать продавцам быстрее принимать решения.

Проект ориентирован на рынок e-commerce и маркетплейсов, где каждый день нужно следить за товарами, ценами, отзывами, конкурентами, рекламой, финансами и качеством карточек.

### 6. API для задач

В проекте реализованы серверные API-маршруты для работы с задачами.

#### Получение задач

```http
GET /api/tasks

Возвращает список задач, отсортированный по дате и времени начала.

Создание задачи
POST /api/tasks

Создаёт новую задачу в базе данных.

Обновление задачи
PATCH /api/tasks/[id]

Позволяет изменить данные конкретной задачи.

Удаление задачи
DELETE /api/tasks/[id]

Удаляет задачу из базы данных.

7. База данных

Для хранения задач используется Prisma и SQLite.

Основная модель данных — Task.

Она содержит:

id: string
title: string
description?: string
project?: string
type: string
priority: string
status: string
date: DateTime
startTime?: string
endTime?: string
repeat?: string
executor?: string
reminder?: string
done: boolean
createdAt: DateTime
updatedAt: DateTime

Такая структура позволяет хранить не только простые задачи, но и полноценные рабочие события с датой, временем, исполнителем, приоритетом и статусом.

8. AI-интеграция

В проект уже добавлена интеграция с Groq SDK.

Есть API-маршруты для проверки AI-подключения и получения списка моделей.

Проверка AI
GET /api/ai/test

Маршрут проверяет наличие GROQ_API_KEY и отправляет тестовый запрос к AI-модели.

Используемая модель:

llama-3.3-70b-versatile
Получение списка моделей
GET /api/ai/models

Маршрут получает список доступных моделей через Groq API.

Это создаёт основу для будущих AI-функций внутри платформы.
